# Backend Server

Node.js + Express backend API.

## Setup

```bash
cd server
npm install
```

## Running the Server

- Development (auto-restart):
  ```bash
  npm run dev
  ```
- Production:
  ```bash
  npm start
  ```

## Database Seeding (Testing / Evaluation)

Populate the database with 15 test users ready for login and assignment:
